Current work at UGA Online

At UGA Online I help build fully online degree programs rather than one-off courses. Each semester, summers included, I develop two to four courses with faculty, usually starting nine to twelve months before launch. I’ve supported programs in geology, data science, and social work, and I keep each program’s courses consistent and professional even when timelines get tight.

  • Course design with faculty

    Each course starts with a weeklong design sprint with the instructor. We set the learning outcomes, outline every weekly module, choose key readings, plan the assessments, and decide which videos we’ll script, film, and edit. From there we iterate through every page and assignment. I refine assignment wording and sequencing, and I write worksheets and instruction briefs that make expectations clear for students and grading straightforward for instructors.

  • Building courses in eLC

    We build courses in custom HTML on a shared design system, so every course in a program looks and works the same way. I build module roadmaps, reading pages, and media pages, and I use React to build web apps for things eLC doesn’t do on its own, such as an automatic, dynamic course calendar. At launch I set up a reusable course template and the live offering, along with an instructor’s guide and a feedback document for the first run.

  • Accessibility

    Everything in our courses is reviewed against WCAG 2.1 AA: HTML pages, video captions and transcripts, PDFs, and Word documents. When a reading or resource falls short, I remediate it before it reaches students.

  • Tools and practices for the team

    Because our pages share a design system, improvements reach every designer on the team. I’ve added new components, refined how core elements are styled, and built React tools like the course calendar. I’ve helped technical programs plan assignments and workflows built on R, RStudio, Quarto, and Jupyter notebooks, helped onboard new members of our Quality and Analytics team, and proposed file naming, organization, and project management practices that are becoming office standards.
